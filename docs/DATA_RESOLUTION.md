# Data resolution

Resolution order is explicit and recursive (maximum ten passes):

1. `valueRef` from the feature-specific static-data JSON.
2. `${ENV:NAME}` secret/environment values.
3. `{{runtime:Alias}}` or `{{buffer:Alias}}` scenario-scoped values.
4. `{{tdm:Source.Key}}` from `TdmOverrides.json` or a normalized environment variable.
5. `{{source:Key}}` from `SourceValueOverrides.json`.

RANDOM values are generated by `DynamicDataCoordinator` immediately before the matching plan instruction and retained in `RunDataContext` for later steps.
